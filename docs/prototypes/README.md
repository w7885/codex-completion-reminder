# 原型状态

`NativeNotificationSettings.cs` 是隔离的通知配置候选实现，供后续方案复用；它尚未接入生产设置保存流程，也未安装到本机。该代码只针对用户级 `config.toml` 的三个通知键设计事务更新。

历史文件 `native-channel-sync.patch` 包含停用自定义审批/选择渠道的方案，与已确认目标冲突，因此不纳入本次提交和远端项目。当前发布材料不应把该补丁描述为可应用的实现。

生产提醒器仍保留自定义审批/选择渠道。UIA 只读探测器单独放在 `experiments/uia-probe/`，当前仅用于识别可行性验证，不能宣称为生产检测器。
