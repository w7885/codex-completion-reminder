# 只读识别验证程序

可丢弃的实验程序，不包含在生产构建中，不是已经安装的通知功能。

`build-probe.ps1` 构建 `dist/CodexReminderUiaProbe.exe`。从自己的 Windows PowerShell/Default 桌面运行，一次读取或传入 0—60 秒进行连续读取。Codex 隔离终端无法代表用户桌面的读取结果。

程序只定位 Windows Store Codex 主窗口，读取单选控件及固定的跳过/发送按钮组合，并实验性匹配启用的固定批准/拒绝按钮组合。审批正例尚未验证，不能据此宣称支持真实审批。不取问题、选项或编辑框正文，不点击、批准或回答，不向网络发送数据。输出仅计数、不透明控件 ID 与可读/未知状态。

最小化后没有读到内容时返回未知，不把它当成请求已解决。运行时标识只用于同一进程内的去重验证，不承诺跨进程一致。

`MsaaProbe.cs` 是另一条 Windows 辅助功能读取路径，需单独编译，当前只验证到前台卡片。它不属于生产功能，读取速度与最小化行为尚需验证。

完整验证结果见 `../../docs/validation/2026-10-11-uia-probe.md`。
